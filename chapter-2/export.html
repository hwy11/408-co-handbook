Browser-side ZIP export

导出项目源码

点击「打包并下载」将当前站点的所有源码文件在浏览器内存中组装为一个 store 模式的 ZIP（无压缩），随后通过 Blob 触发本地保存 —— 不需要服务端介入。

关于这个导出方案

  • 使用纯 JavaScript 手写 ZIP 结构：Local File Header + Central Directory + EOCD。
  • 压缩方法采用 store（0x00），即不压缩，因此无需实现 deflate。
  • CRC32 通过 256 项查表法实时计算；文件名启用 UTF-8 编码标志（bit 11）。
  • 解压后目录结构与线上一致，可直接作为本地项目重新运行。
  • 如需加入 / 移除文件，修改本页脚本里的 FILES 数组即可。
